Tesauro de Direccionamiento IP

Tesauro de conceptos relacionados con el direccionamiento en redes IP. IPv4 e IPv6 se consideran especializaciones de este área.

ID Término preferido Definición
ip_direccionamiento Direccionamiento IP Conjunto de normas para asignar y representar direcciones en redes IP.
ip_ipv4 IPv4 Versión 4 del Protocolo de Internet, con direcciones de 32 bits.
ip_ipv6 IPv6 Versión 6 del Protocolo de Internet, con direcciones de 128 bits.
ip_cidr Notación CIDR Forma de expresar prefijos de red añadiendo /longitud a la dirección.
