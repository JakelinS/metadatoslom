Tesauro de Informática

Tesauro general con algunos conceptos básicos de informática. Se utiliza como nivel superior para otros tesauros más específicos (redes, direccionamiento IP, IPv6, etc.).

ID Término preferido Definición
info Informática Disciplina que estudia el tratamiento automático de la información mediante ordenadores.
info_hw Hardware Conjunto de elementos físicos de un sistema informático.
info_sw Software Programas y datos que permiten realizar tareas en un sistema informático.
info_redes Redes de computadores Área de la informática que se ocupa de la interconexión de equipos para compartir recursos.
