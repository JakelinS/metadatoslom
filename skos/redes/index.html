Tesauro de Redes de computadores

Tesauro con algunos términos generales del área de redes de comunicaciones. Sirve como nivel intermedio entre el tesauro de Informática y tesauros más específicos como Direccionamiento IP o IPv6.

ID Término preferido Definición
redes Redes de computadores Conjunto de dispositivos interconectados que comparten recursos e información.
redes_lan Red LAN Red de área local que cubre un espacio reducido, como un aula o una oficina.
redes_wan Red WAN Red de área amplia que conecta redes geográficamente dispersas.
redes_ruteador Router Dispositivo encargado de encaminar paquetes entre diferentes redes.
