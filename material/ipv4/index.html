IPv4: conceptos básicos

Esta página resume los aspectos esenciales de IPv4 que se dan por conocidos en el objeto de aprendizaje de Introducción a IPv6.

Direcciones IPv4

  • Una dirección IPv4 tiene 32 bits.
  • Se representa como cuatro números decimales entre 0 y 255 separados por puntos, por ejemplo: 192.168.1.10.
  • Cada número (octeto) representa 8 bits.

Red y host

  • La dirección se divide en una parte de red y una parte de host.
  • El tamaño de cada parte se indica con un prefijo, por ejemplo: 192.168.1.0/24.

Ejemplo

  • Dirección: 192.168.1.25
  • Prefijo: 192.168.1.0/24 (red doméstica o de pequeña oficina típica).
