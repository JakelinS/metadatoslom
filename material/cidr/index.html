Notación CIDR

La notación CIDR se utiliza para indicar cuántos bits de una dirección IP pertenecen a la parte de red.

Cómo se escribe

  • Se representa como dirección/prefijo, por ejemplo: 192.168.1.0/24.
  • El número tras la barra indica el número de bits de red.

Ejemplos en IPv4

  • 10.0.0.0/8: red privada grande.
  • 172.16.0.0/16: red privada de tamaño medio.
  • 192.168.1.0/24: red típica de hogar o pequeña oficina.

Relación con IPv6

  • En IPv6 se usa la misma idea de prefijo, por ejemplo 2001:db8::/64.
  • El prefijo /64 indica que los 64 primeros bits corresponden a la red.

Una vez entendida la notación CIDR, puedes continuar con el objeto de aprendizaje de Introducción a IPv6.
