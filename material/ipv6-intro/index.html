OA: Introducción a IPv6

Clasificación (tesauro): Informática → Redes de computadores → Direccionamiento IP → IPv6.

1. Objetivos de aprendizaje

  • Reconocer la estructura de una dirección IPv6.
  • Aplicar reglas de compresión y notación en direcciones IPv6.
  • Comprobar la pertenencia de direcciones a un prefijo IPv6 dado.

2. Requisitos previos

Se recomienda haber trabajado previamente:

  • Repaso de IPv4.
  • Repaso de notación de prefijos y CIDR.

3. Contenidos

3.1. Conceptos clave

  • IPv6 utiliza direcciones de 128 bits, representadas como 8 grupos hexadecimales de 16 bits:
    2001:0db8:0000:0000:0000:ff00:0042:8329
  • Prefijos habituales en redes LAN: /64.

3.2. Reglas de compresión

  • Se pueden eliminar ceros a la izquierda en cada grupo.
  • Solo se puede usar :: una vez por dirección (representa una cadena de grupos 0000).
  • Ejemplo de compresión:
    2001:0db8:0000:0000:0000:ff00:0042:8329 → 2001:db8::ff00:42:8329

4. Actividad

  1. Comprime la siguiente dirección IPv6 aplicando las reglas de abreviación:
    2001:0db8:0000:0000:0000:0000:0000:0001.
  2. Comprueba si la dirección 2001:db8::10 pertenece al prefijo 2001:db8::/64. Justifica la respuesta.
  3. Escribe un ejemplo de dirección de enlace local válida (rango fe80::/10) y explica en qué tipo de red se usaría.

5. Autoevaluación

  1. ¿Cuántos bits tiene una dirección IPv6? ¿Cómo se representa en notación textual?
  2. ¿Cuándo puedes usar :: en una dirección IPv6 y cuántas veces como máximo?
  3. Da un ejemplo de prefijo /64 en una LAN e indica qué parte corresponde a la red.
