Portada Tesauro SKOS (TTL) Direccionamiento IP IPv6

OA: Introducción a IPv6

Clasificación (tesauro): Informática → Redes de computadores → Direccionamiento IP → IPv6.

1. Objetivos de aprendizaje

  • Reconocer la estructura de una dirección IPv6.
  • Aplicar reglas de compresión y notación.
  • Comprobar pertenencia de direcciones a un prefijo.

2. Requisitos previos

  • Repaso de IPv4 y CIDR (si están publicados).

3. Contenidos

3.1 Conceptos clave

  • 128 bits (8 grupos hex de 16 bits): 2001:0db8:0000:0000:0000:ff00:0042:8329
  • Prefijos habituales en LAN: /64.

3.2 Reglas de compresión

  • Eliminar ceros a la izquierda en cada grupo.
  • Un solo :: por dirección (cadena de 0000).
  • Ej.: 2001:db8::ff00:42:8329

4. Actividad

  1. Comprime: 2001:0db8:0000:0000:0000:0000:0000:0001.
  2. ¿Pertenece 2001:db8::10 a 2001:db8::/64?
  3. Ejemplo de enlace-local válido (fe80::/10).

5. Autoevaluación

  • ¿Cuántos bits tiene IPv6? ¿Cómo se escriben en notación textual?
  • ¿Cuándo puedes usar :: y cuántas veces?
  • Da un ejemplo de prefijo /64 en una LAN.
