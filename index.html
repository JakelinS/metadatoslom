Práctica SKOS: Metadatos LOM (Learning Object Metadata)

Página principal del vocabulario Metadatos LOM para Redes de computadores (ASIR).

El vocabulario define conceptos del área de redes de computación para alumnado de primer curso del ciclo de grado superior de ASIR. Se publica en formato SKOS (RDF/Turtle) y sus URIs pueden utilizarse en LOM/LOM-es (Categoría 9: Classification) mediante taxonPath.

URL pública del tesauro: https://jakelins.github.io/metadatoslom/skos/tesauro-redes.ttl

URIs SKOS para usar en LOM (Categoría 9 → taxonPath)

Inserta estas URIs en <classification> → <taxonPath> → <taxon><id> y usa la etiqueta en <entry> (lang=es):

  • https://jakelins.github.io/metadatoslom/skos/informatica — Informática
  • https://jakelins.github.io/metadatoslom/skos/redes — Redes de computadores
  • https://jakelins.github.io/metadatoslom/skos/ip — Direccionamiento IP
  • https://jakelins.github.io/metadatoslom/skos/ipv6 — IPv6
